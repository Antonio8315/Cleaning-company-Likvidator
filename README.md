# 🧼 Likvidator — Професійний Клінінг

Сучасний, адаптивний та швидкий веб-додаток для замовлення послуг професійного прибирання квартир, будинків та котеджів. Проект створено на базі сучасного стеку технологій з акцентом на UX/UI та адаптивність під будь-які пристрої.

## 🚀 Живе демо (Live Demo)
Сайт успішно задеплоєно на Vercel. Ви можете переглянути його за посиланням:
👉 [](https://cleaning-company-likvidator-sigma.vercel.app/)

---

## 🛠 Стек технологій
У цьому проекті використовуються сучасні інструменти фронтенд-розробки:
* **React 19** (Functional Components, Hooks) — для побудови інтерфейсу.
* **React Router DOM** — для клієнтського роутингу та миттєвого переходу між сторінками.
* **Vite** — як супершвидкий інструмент збірки та локального сервера розробки.
* **HTML5 / CSS3** (CSS Grid, Flexbox, Media Queries) — для адаптивної верстки без сторонніх UI-бібліотек.

---

## ✨ Реалізований функціонал
1. **Інтерактивна вітрина послуг** — картки з детальним описом та модальними вікнами замовлення.
2. **Адаптивний Футер (Footer)** — сучасна триколонкова структура з навігацією, контактами та картою сайту.
3. **Scroll To Top** — автоматичне прокручування сторінки вгору при переході між маршрутами React Router.
4. **Компонент відгуків (ReviewCart)** — динамічний та перевикористовуваний компонент картки відгуку, який адаптує свої кольори та стилі залежно від того, на якій сторінці він відображається.
5. **Адаптивний банер (Hero Section)** — ідеально масштабується на мобільних пристроях, зберігаючи пропорції картинки без обрізання важливих елементів.
6. **Конфігурація для Vercel** — налаштовані рерайти (`vercel.json`) для уникнення помилки 404 при ручному оновленні сторінок SPA.
